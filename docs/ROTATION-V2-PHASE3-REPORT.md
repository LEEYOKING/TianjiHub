## 3. 公式与口径变化（交付 3）

### 3.1【口径变化·核心】主页筛选的适用范围（修 P0-3）

| | 旧口径 | 新口径 |
|---|---|---|
| 类型/关键词筛选 | 只作用于**统计表 + 热力网格**；每日榜单、行为画像**不受影响** | **统一作用于本页全部模块**：近期轮动观察、每日最强/最弱榜、统计表、热力网格、高级研究（含轮动关系） |

- 依据：任务书 §9.4「各模块不得各用一套口径」、审计 §7 口径统一原则。
- 与"规则栏 · 板块范围"（`rule.scope`）的关系：两者**取交集**（`本页筛选 ⊆ 规则范围`）。界面已写明。
- **影响范围（属有意变更）**：当用户使用本页筛选时，每日榜单 / 行为画像 / 轮动关系的显示范围会随之收缩（此前不变）。默认（筛选=全部 + 无关键词）时显示完全不变。
- 空集提示：筛选与规则范围冲突时，榜单/统计表给出"当前筛选下没有符合条件的板块"。

### 3.2 新增指标：最近活跃日期

```
lastActiveAgo  = min(lastStrongAgo, lastWeakAgo)        // 取最近一次强势「或」弱势事件的交易日步长
lastActiveDate = dates[total − 1 − lastActiveAgo]       // 无任何事件 → null
```
缺失日一律排除；与既有 `lastStrongAgo / lastWeakAgo` 同源、同口径。

### 3.3 新增指标：活跃度评分分项（数值不变，仅显式化）

```
score = round( clamp01( 0.35·f1 + 0.25·f2 + 0.20·f3 + 0.20·f4 ) × 100 )
  f1 = clamp01(强势频率 / 0.20)                         // 强势频率分
  f2 = 无强势事件 ? 0 : exp(−(ln2/5)·距最近强势交易日数)  // 近期活跃分（半衰期 5 日）
  f3 = clamp01(独立周期数 / 有效日数 / 0.10)             // 独立周期频率分
  f4 = 基准缺失 ? 0.5 : clamp01(0.5 + 相对超额 / 0.20)   // 相对市场趋势分
```
权重由 `SCORE_WEIGHTS` 统一维护。**与旧实现逐位一致**（0.35/0.25/0.2/0.2）。

### 3.4【新增能力】近期轮动观察的判定规则（实验参数）

判定顺序 = 优先级顺序；同一板块**只保留第一个命中的标签**（任务书 §5.3 去重）。

| 优先级 | 标签 | 触发条件（默认阈值） | 触发依据（由统计量生成） | strength（同标签内排序用） | 最近事件日期 |
|---|---|---|---|---|---|
| 0 | 沉寂后重新活跃 | `距最近强势 ≤ 4 日` 且 `此前空档 ≥ 24 日` | 强势次数 / 距最近强势 / 此前空档 | 此前空档 | 最近强势日 |
| 1 | 反复脉冲 | `独立周期数 ≥ 5` 且 `周期平均间隔 ≥ 12 日` | 独立周期数 / 周期平均间隔 | 周期数×10 + 间隔 | 最近强势日 |
| 2 | 持续活跃 | `强势次数 ≥ 12` 且 `距最近强势 ≤ 3 日` | 强势次数 / 距最近强势 | 强势次数 | 最近强势日 |
| 3 | 强弱交替 | `min(强势,弱势) ≥ 12` 且 `min/max ≥ 0.8` | 强势次数 / 弱势次数 | min(强势,弱势) | 最近活跃日 |
| 4 | 相对走强 | `相对基准超额 ≥ 28%` 且 `覆盖率 ≥ 90%` | 相对基准超额（简单超额口径） | 相对超额 | 最近活跃日 |

**所有标签共同的入口门槛**：`覆盖率 ≥ 60%`（数据不足不下结论）。
**排序**：优先级升序 → strength 降序 → 板块 id 升序（同样数据结果可复现）。
**折叠态（首屏）**：用 `pickHighlightObservations` 做**标签多样性**挑选（各标签先各取 1 条，不足再补齐），避免首屏 3 条清一色同一标签。

**默认阈值的取值依据（实测，2026-10-13 归档 / 默认规则 60 日·TOP10·±2.5%·OR）**：
该规则下事件绝对次数整体偏高（全市场强势次数中位数 4、弱势 4、独立周期 4），若按"直觉小阈值"会命中 654/663 个板块（99%），标签失去区分度。因此把阈值统一取到全市场约 **p90~p95 分位**附近，使 5 类标签合计命中 **92/663（≈14%）**，分布为：沉寂后重新活跃 27 / 反复脉冲 19 / 持续活跃 20 / 强弱交替 9 / 相对走强 17。

> 重要限定：阈值是**绝对次数**而非分位数，因此规则大幅变化时（如窗口缩到 15 日、改为 AND 逻辑）命中数会随之变化，极端情况下可能为 0。此时界面给出空状态说明（"这是当前统计窗口与观察阈值下的结果…可调整规则"）。

### 3.5 未变动（明确声明）

- 事件判定 `strong/weak/largeUp/largeDown`、组合逻辑、间隔 `gap_i` / 空档 `empty_i = gap_i−1`、独立事件簇、复合收益、最大回撤、相对基准两种口径 —— **均沿用阶段 2 结论，本阶段 0 改动**。
- 位置型取值一律经 `toWindowView`（阶段 2 已修），本阶段新增的观察模块不涉及位置型取值。

## 6. 已知问题（交付 6）

1. **观察阈值是绝对次数，规则敏感**：规则大幅变化（窗口 15 日、AND 逻辑等）时命中数会明显变化，可能为 0。当前只有默认值，**不可在 UI 调整**（阶段 5 配置器暴露）。空状态已做说明。
2. **观察阈值未纳入规则存档**：与 `DEFAULT_RULE.version` 解耦，不会随规则版本作废；阶段 5 若要让用户自定义，需要单独设计存储与版本策略。
3. **本页筛选 × 规则范围取交集**：二者冲突（如规则范围=行业、本页筛选=概念）会得到空集，界面有说明但**不是防呆**；阶段 5 配置器可考虑联动提示。
4. **关联分析下移后仍受本页筛选影响**：极窄搜索下参与统计的样本过小，虽有"样本不足"标注，但关系结论的可靠性会下降。
5. **窄屏验证证据不完整**：本环境的浏览器截图能力不可用，且 `document.documentElement.scrollWidth` 读取返回 0；仅以 `body.scrollWidth == 视口宽`（372px）与媒体查询命中（2 列）间接证明无横向溢出。建议在真实设备上再目视确认一次。
6. **「展开全部」一次性渲染 92 条**：当前无虚拟滚动；实测渲染无卡顿，但若未来阈值放宽导致条数过百，需考虑分页/虚拟列表。
7. **`最小覆盖率` 与 `相对走强覆盖率` 两档**：普通标签 0.6、相对走强 0.9，含义已在词条说明，但两档并存对普通用户略繁；阶段 4/5 可合并展示口径。
8. **未做**：§10 观察清单（收藏/跨日验证）、§7.5 规则方案保存、§9.2 数据状态机（仅做了榜单的"非当日盘后快照"标记）。
